# Design: 2brn Electron App Packaging

**Date:** 2026-04-25  
**Status:** Approved  
**Scope:** Configure `electron-builder` to produce a distributable `2brn.app` / `.dmg` that bundles the Python daemon (src + venv) inside the app bundle.

---

## Goal

Run `pnpm electron:build` from `ui/` and get a `release/2brn-*.dmg` that:
- Installs `2brn.app` to `/Applications/`
- Includes the Python daemon (`daemon/src/` + `daemon/.venv/`) at `Contents/Resources/daemon/`
- Has the 🧠 brain emoji as the app icon
- Works on both Apple Silicon and Intel Macs (universal build)
- Requires no code signing (personal use — Gatekeeper bypass via right-click → Open)

---

| File | Action | Purpose |

## `electron-builder.yml`

```yaml
appId: com.sasidharan.2brn
productName: 2brn
directories:
  output: release
  buildResources: build

mac:
  icon: build/icon.icns
  target:
    - target: dmg
      arch: [arm64, x64]
  category: public.app-category.productivity

dmg:
  title: "2brn"

extraResources:
  - from: ../daemon/src
    to: daemon/src
  - from: ../daemon/.venv
    to: daemon/.venv
  - from: ../daemon/pyproject.toml
    to: daemon/pyproject.toml
```

### Why `extraResources`

`main.ts` already resolves the daemon path in production mode as:

```ts
return path.join(process.resourcesPath, 'daemon')
```

`electron-builder`'s `extraResources` copies files to `Contents/Resources/` inside the `.app` — so `daemon/src/` lands at `Contents/Resources/daemon/src/` and `daemon/.venv/` at `Contents/Resources/daemon/.venv/`. Zero changes to `main.ts`.

### Expected output size

The daemon `.venv` is ~423 MB. The final `.dmg` will be approximately **350–450 MB** (DMG compression helps).

### Universal build

`arch: [arm64, x64]` produces two separate `.dmg` files (one per arch). electron-builder does not produce a true fat binary when bundling native Python extensions in a venv — separate arch builds are the correct approach.

## Icon Generation

### Strategy

Use only tools already available on the machine:
1. **Pillow** (already in `daemon/.venv`) renders the 🧠 emoji at 1024×1024 using the system Apple Color Emoji font at `/System/Library/Fonts/Apple Color Emoji.ttc`
2. **`sips`** (macOS built-in) scales the 1024px PNG to all required iconset sizes
3. **`iconutil`** (macOS built-in) assembles the `.iconset/` folder into `build/icon.icns`

### `ui/scripts/generate-icon.sh`

```bash
#!/usr/bin/env bash
set -euo pipefail

REPO_ROOT="$(cd "$(dirname "$0")/../.." && pwd)"
VENV_PYTHON="$REPO_ROOT/daemon/.venv/bin/python3"
BUILD_DIR="$REPO_ROOT/ui/build"
ICONSET_DIR="$BUILD_DIR/icon.iconset"
OUTPUT_ICNS="$BUILD_DIR/icon.icns"
SOURCE_PNG="$BUILD_DIR/icon_1024.png"

mkdir -p "$ICONSET_DIR"

# Step 1: render brain emoji at 1024x1024 using Pillow + Apple Color Emoji font
export OUTPUT_PNG="$SOURCE_PNG"
"$VENV_PYTHON" - <<'PYEOF'
import os
from PIL import Image, ImageDraw, ImageFont

size = 1024
img = Image.new("RGBA", (size, size), (0, 0, 0, 0))
draw = ImageDraw.Draw(img)
font = ImageFont.truetype("/System/Library/Fonts/Apple Color Emoji.ttc", 960)
bbox = draw.textbbox((0, 0), "🧠", font=font, embedded_color=True)
x = (size - (bbox[2] - bbox[0])) // 2 - bbox[0]
y = (size - (bbox[3] - bbox[1])) // 2 - bbox[1]
draw.text((x, y), "🧠", font=font, embedded_color=True)
img.save(os.environ["OUTPUT_PNG"], "PNG")
PYEOF

echo "Rendered brain emoji to $SOURCE_PNG"

# Step 2: generate all required iconset sizes with sips
for SIZE in 16 32 64 128 256 512 1024; do
  sips -z $SIZE $SIZE "$SOURCE_PNG" --out "$ICONSET_DIR/icon_${SIZE}x${SIZE}.png" > /dev/null
  if [[ $SIZE -le 512 ]]; then
    DOUBLE=$((SIZE * 2))
    sips -z $DOUBLE $DOUBLE "$SOURCE_PNG" --out "$ICONSET_DIR/icon_${SIZE}x${SIZE}@2x.png" > /dev/null
  fi
done

echo "Generated iconset sizes"

# Step 3: compile .icns
iconutil -c icns "$ICONSET_DIR" -o "$OUTPUT_ICNS"
echo "✓ Icon generated at $OUTPUT_ICNS"

# Cleanup
rm -rf "$ICONSET_DIR" "$SOURCE_PNG"
```

## Build & Install Steps (manual)

Once the config and icon are in place:

```bash
# 1. Generate icon (once, or whenever you want to update it)
bash ui/scripts/generate-icon.sh

# 2. Build the app (from ui/ directory)
nvm --version   # trigger nvm lazy init
cd ui
pnpm electron:build

# 3. Install — open the DMG and drag 2brn to Applications
open release/2brn-*.dmg

# 4. Update start-2brn.sh — APP_PATH can now be left empty since open -a "2brn" will work
# Or set explicitly:
# APP_PATH="/Applications/2brn.app"
```

### First launch Gatekeeper bypass

Because the app is unsigned, macOS will block the first launch:
- Right-click `2brn.app` in Applications → **Open** → **Open** in the dialog
- After this first override, double-click and `open -a "2brn"` work normally

---

## Out of Scope

- Code signing / notarization (personal use only)
- Windows / Linux targets
- Auto-update (Squirrel/electron-updater)
- Pruning the venv before bundling (future optimisation if size is a concern)
- Custom app icon beyond the emoji (replace `ui/build/icon.icns` any time)
